# Blender gear Zigmund&Shtien BH-339M

**Description**

This part is used in the Zigmund & Shtien BH-339M blender. It may also fit other blenders from this company.
The gear itself is used in the dicing attachment.
After installing the part in the blender, the gear must be lubricated with petroleum jelly to ensure proper lubrication of the gearbox.
